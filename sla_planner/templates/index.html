ℹ️ Что произойдёт при отправке в Zabbix:

  • 2. Через Zabbix API (sla.update) будет добавлено исключение простоя
  • 3. В указанный период недоступность сервиса не будет учитываться в SLA-отчёте
  • 4. Исключение будет названо: «ПР: [название] ([сервис])»
